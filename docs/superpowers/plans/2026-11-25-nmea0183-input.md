# NMEA 0183 Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The plotter shows the boat from an NMEA 0183 stream (TCP client or UDP listener) as an alternative to Signal K, chosen by `[input] source` in `plotter.toml`.

**Architecture:** Every source is one tokio task that gets a `LiveFeed` (the three senders that exist now). The NMEA 0183 source is a transport (TCP/UDP bytes to lines) and a pure decoder (line to `BoatState` update). Fix and heading freshness is decided once, in `BoatState::expired` called from `Session`, for every source.

**Tech Stack:** Rust, tokio (`full` already on), SDL2. No new dependency.

**Spec:** `docs/nmea0183-input-design.md` (decisions 1-17). Research: `docs/nmea0183-input-research-2026-11-25.md`.

## Global Constraints

- New identifiers, comments, docs and commit messages in English, ASD-STE-100 style. Log messages in French.
- Quality gate before each commit: `cargo fmt -- --check` silent, `cargo build` 0 warnings, `cargo test` all pass, `cargo clippy --all-targets` 0 warnings. In Git Bash: `export PATH="$HOME/.cargo/bin:$PATH"`.
- Tests write only to `std::env::temp_dir()`. No `#[allow(dead_code)]`.
- Coordinates are `(lon, lat)`; validate finite, lon -180..=180, lat -90..=90 before storing.
- Degrade, never exit: no source error may stop the app.
- Units in `BoatState`: SOG m/s, COG and heading radians true. 1 kn = 1852/3600 m/s.
- Timeouts: `FIX_TIMEOUT` = 10 s, `HEADING_TIMEOUT` = 10 s.
- Defaults: `source = "signalk"`; `[nmea0183] transport = "tcp"`, `address = "127.0.0.1:10110"`; Signal K `heading = "navigation.headingTrue"`; `boat_color = [255, 0, 0, 255]`; `boat_no_fix_color = [128, 128, 128, 255]`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A source that stops sending, but whose connection stays open** (TCP with no data): the marker must go grey after 10 s, and the TCP client must reconnect after 30 s. Pinned by the `Session::expire_boat` test (Task 2) and the read-timeout constant used in Task 5.
2. **Signal K republishes an old fix with a new COG**: the old `fixed_at` must not be refreshed, so the marker still goes grey. Pinned by `a_course_update_does_not_refresh_the_fix_time` (Task 3).
3. **A garbage or binary stream** (wrong port, a long line with no newline): no panic, no unbounded buffer. Pinned by `a_line_longer_than_the_limit_is_dropped` and `bytes_that_are_not_utf8_are_dropped` (Task 5).
4. **The simulator's no-fix sentences** (13-field RMC, empty fields) and minutes `60.0000`: no position change, no panic. Pinned by tests in Task 4.
5. **`nmea2k` or a source task that ends**: the app keeps running, one ERROR. Pinned by `a_closed_channel_is_reported_once` (Task 3).

### Task 4: NMEA 0183 decoder

**Files:**
- Create: `src/nmea0183.rs`
- Modify: `src/main.rs` (`mod nmea0183;`)

**Interfaces:**
- Produces:
  - `pub struct Decoder` (private fields: the current `BoatState`, the last RMC variation `Option<f64>` in degrees, east positive).
  - `pub fn Decoder::new() -> Self`, `pub fn boat(&self) -> BoatState`.
  - `pub struct Update { pub boat_changed: bool, pub track_point: Option<(f64, f64)> }`, `Default`.
  - `pub fn Decoder::apply(&mut self, line: &str, now: Instant) -> Update`.
- Rules (spec decisions 8-12 and "Structure"):
  - Trim CR/LF. If the line starts with `\`, drop it up to and including the second `\`.
  - Start `$`; `!` and others give no update. Need `*hh`; XOR of the bytes between `$` and `*` must equal `hh` (hex, either case). No checksum = rejected.
  - Sentence type = characters 3-5 after `$` (talker ignored). Only `RMC`, `HDT`, `HDG`; every other type gives no update.
  - RMC (fields 1-based after the type): status field 2 must be `A`; field 12, when present and not empty, must not be `N` or `E`. Lat `ddmm.mmmm` + N/S, lon `dddmm.mmmm` + E/W; minutes must be < 60; then the boundary check. On a fix: set position, `position_valid = true`, `fixed_at = Some(now)`, `track_point = Some((lon, lat))`, `boat_changed`. SOG field 7 (knots × 1852/3600), COG field 8 (degrees to radians); an empty field keeps the last value. Variation fields 10-11 (W negative) are kept when present. On no fix: `position_valid = false`, `boat_changed`, no position change, no track point.
  - HDT field 1: degrees true. HDG: field 1 magnetic, fields 4-5 variation (W negative); else the last RMC variation; else no update. True = magnetic + variation. Deviation (fields 2-3) is ignored. Normalise to 0..2π. Sets `heading`, `heading_at = Some(now)`, `boat_changed`.

### Task 5: NMEA 0183 transport and wiring

**Files:**
- Create: `src/nmea0183/transport.rs` (declare `mod transport;` in `nmea0183.rs`)
- Modify: `src/nmea0183.rs` (`pub async fn run`), `src/app.rs` (`Nmea0183` arm), `CLAUDE.md` (module table, threads section), `README.md`

**Interfaces:**
- Consumes: `Decoder`, `Update` (Task 4); `LiveFeed` (Task 3); `Nmea0183Config`, `Transport` (Task 1).
- Produces:
  - `pub(super) const MAX_LINE: usize = 100`, `pub(super) const READ_TIMEOUT: Duration` = 30 s.
  - `pub(super) struct LineSplitter` with `pub fn push(&mut self, bytes: &[u8]) -> Vec<String>`: splits on `\n`; keeps a partial line between calls; a line longer than `MAX_LINE` (including a partial one that grows past it) is dropped up to its next `\n`; a line that is not UTF-8 is dropped.
  - `pub async fn run(config: Nmea0183Config, feed: LiveFeed)`: never returns. Logs INFO with transport and address at start.
    - TCP: connect to `address`; on failure WARN and wait with the Signal K back-off (1 s more per try, at most 10 s); read with `tokio::time::timeout(READ_TIMEOUT, ...)`; EOF, error or timeout → WARN and reconnect. One `LineSplitter` per connection.
    - UDP: bind `address` with `UdpSocket::bind` (and `set_broadcast(true)`); on failure ERROR, wait 10 s, try again. Each datagram goes through a fresh `LineSplitter` with a final `\n` added.
    - Each line: `decoder.apply(&line, Instant::now())`; on `boat_changed` send `decoder.boat()` on `feed.boat`; on `track_point` send it on `feed.track`. Send errors are ignored. The AIS sender is not used (decision 7).
